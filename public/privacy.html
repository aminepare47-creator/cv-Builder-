Politique de confidentialité

Dernière mise à jour : à compléter par l'éditeur du site.

CV Builder Pro (« le Site », « nous ») respecte votre vie privée. Cette page explique quelles données sont traitées lorsque vous utilisez l'application, et comment.

1. Les données de votre CV restent sur votre appareil

Le contenu de votre CV (informations personnelles, expériences, formations, compétences, etc.) est enregistré uniquement dans le stockage local de votre navigateur (localStorage). Il n'est jamais envoyé ni stocké sur nos serveurs. Si vous videz les données de votre navigateur ou changez d'appareil, ces informations ne sont pas récupérables ailleurs.

2. Fonction d'assistance par intelligence artificielle

Si vous utilisez la fonctionnalité d'aide à la rédaction par IA, le texte que vous soumettez à cet outil (par exemple une description de poste à reformuler) est transmis à un service tiers de génération de texte (Groq et/ou Google Gemini, selon disponibilité) via notre serveur, dans le seul but de générer une réponse. Ce texte n'est pas conservé par nos soins après la requête. Cette fonctionnalité est optionnelle : si vous ne l'utilisez pas, aucune donnée de ce type n'est transmise.

3. Aucun compte, aucune vente de données, aucune publicité

Le Site ne nécessite aucune inscription et ne collecte pas d'adresse e-mail ni de mot de passe. Nous ne vendons aucune donnée personnelle.

4. Installation en tant qu'application (PWA)

Le Site peut être installé sur votre appareil et fonctionner hors ligne grâce à un service worker technique, qui met en cache les fichiers de l'application pour accélérer les chargements futurs. Il ne collecte aucune donnée personnelle.

5. Vos droits

Comme vos données de CV restent sur votre propre appareil, vous en gardez le contrôle total : vous pouvez les modifier ou les supprimer à tout moment via le bouton « Vider » de l'application, ou en effaçant les données de site de votre navigateur.
